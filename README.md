# Overview

This lab demonstrates the fundamentals of Kubernetes using Minikube.

The tasks covered:

- Kubernetes cluster architecture
- Pod creation and management
- Deployments and self-healing
- Scaling applications
- Kubernetes Services
- Rolling updates and rollback
- Multi-tier application deployment
- Persistent storage using StatefulSets
- Metrics monitoring
- Troubleshooting Kubernetes failures
